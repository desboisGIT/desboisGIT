## About Me

I'm **Robin CHAILLOU** (`desboisGIT`), a French computer science student currently studying in the **MP2I preparatory program** at **Lycée Kléber**.

My primary interests lie at the intersection of **computer graphics**, **physically-based rendering**, and **artificial intelligence**. I enjoy building projects that combine mathematics, graphics programming, machine learning, and high-performance computing.

While I previously focused on **full-stack web development**, my current work is centered around **computer graphics research**, particularly neural approaches for Monte Carlo denoising and real-time rendering.

---

## Current Research

I'm currently developing an **end-to-end open-source pipeline** for neural Monte Carlo denoising.

The project includes:

- Automated Blender dataset generation
- Physically-based path tracing
- Large-scale auxiliary buffer generation
- Online patch extraction pipeline
- Statistical dataset validation
- Neural denoiser training using PyTorch
- Benchmarking against existing denoisers (OIDN and related work)

Current research topics include:

- Monte Carlo Rendering
- Path Tracing
- Neural Denoising
- Deep Learning
- Computer Vision
- GPU Computing
- Real-Time Rendering
- Rendering Optimization
